# PAI最終課題：自分の腕を学ぶAIロボットアームが文字・図形を描く

2関節のロボットアーム（MuJoCoシミュレータ）が、ニューラルネットワークで学んだ「自分の腕の動かし方」を使って、イニシャル「TO」・ハート・星をなぞって描きます。

## 仕組み

1. **体験（モーターバブリング）**：ロボットが腕をランダムな姿勢に2万回動かし、「関節の角度」と「手先の位置」の組を記録します。
2. **学習**：ニューラルネットワーク（scikit-learn の MLPRegressor）が「手先をこの位置に置くには、関節を何度にすればよいか」を学びます。
3. **推論**：描きたい図形の各点をAIに入力し、出力された関節角度に向けてPD制御でモーターを動かします。文字は複数の線（ストローク）に分け、線と線の間はペンを上げて移動します。
4. **動画**：左にシミュレーション映像、右に「お手本（灰色）」と「AIが描いた線（赤）」を並べて保存します。

## 結果

| 図形 | 平均誤差 | 最大誤差 |
|---|---|---|
| イニシャル「TO」 | 0.59 cm | 1.54 cm |
| ハート | 0.60 cm | 1.43 cm |
| 星 | 0.66 cm | 1.71 cm |

## 実行方法（Google Colab）

1. `PAI_robot_draw.ipynb` を Google Colab で開きます。
2. セル1〜5を上から順に実行します。
3. `draw_robot.mp4`（約2分）が作成され、ダウンロードされます。

## 使用ツール

- シミュレータ：MuJoCo（Gymnasium の Reacher-v5 環境）
- AI：scikit-learn MLPRegressor（ニューラルネットワーク）
- 動画作成：imageio
- 実行環境：Google Colab
